Privacy & data handling

AXO runs as a web app. Where information is stored and who receives it depends on the feature you use and the connections you enable.

Stored on this device

Chat history, preferences, bot definitions, plugin settings, saved memory and other browser features are stored in this browser's local storage unless you explicitly use cloud sync. Clearing browser/site data can remove them. Local browser storage is not encrypted by AXO.

Credentials and connections

Saved API keys and connection credentials are also kept in browser storage in this version, which is not an encrypted vault. When a feature is used, the relevant data or credential is sent to your AXO server to perform that action. Keep your device locked and never share a browser profile you have saved keys in.

External AI and public sources

Messages sent to an AI provider may be processed under that provider's terms. Public lookups such as Wikipedia, web search, weather and image search send the query to the relevant public provider. Browser shortcuts to ChatGPT, Claude, Gemini, Gmail and social sites only open those websites; they do not grant AXO private account access.

Server and cloud storage

AXO's server processes requests and may hold backend files such as notes and libraries depending on the hosting environment. Render's local filesystem may be temporary unless a persistent disk is configured. Optional Firebase cloud sync stores only the data you choose to sync in your own Firebase project; credentials are excluded from the backup/sync bundle.

Photos and files

When you submit an image for analysis, it is sent to the AI provider configured for vision. Only upload files you are comfortable sharing with that provider. PDF study extraction processes the supplied document through AXO's configured service when AI processing is requested.

Export or delete your dataUse the Data section to export chats and preferences, clear connection keys, or delete local history. Also delete any optional copies in your Firebase project or provider accounts.

AXO does not claim end-to-end encryption, anonymous account access, or automatic deletion from third-party providers. This summary describes the current app build; hosting and provider retention are governed by those services.

About AXO

AXO Assistant · v16Personal assistant by AXU

AXO combines a Python/Flask backend, a browser interface, public-data tools and optional AI connections. Core commands such as calculations, selected public lookups and app shortcuts can run without an AI API key. AI-powered reasoning depends on a provider connection or a supported external AI website handoff.

AXO Bots

Personal bots and bot teams

Create focused assistants with their own names, instructions, knowledge notes, links and visual identity. Bots can use permitted AXO tools, and teams can pass one bot's result to the next as a workflow. Bot conversations and definitions are saved in this browser unless you export or sync them.

Tools, plugins and integrations

AXO's agent can use approved tools such as public search, notes, weather, charts and connected Gmail, GitHub or Firebase functions. Sending messages, editing external records or other consequential actions may ask for confirmation. A browser shortcut is not the same as an API integration.

Browser-based AI choices

ChatGPT, Claude and Gemini can be opened without configuring their API keys in AXO. Use the context handoff in AI & API to copy a selected snapshot into the external website yourself.

AXO is a personal assistant interface, not an official product of OpenAI, Anthropic or Google. Their logos and names identify the external services only.
