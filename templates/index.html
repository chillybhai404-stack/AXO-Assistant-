Built-in public data integrations

No API keys needed: weather, maps/geocoding, Wikipedia, image search, news feeds, earthquakes, ISS tracking, currency rates, public holidays, GitHub search, books, recipes, dictionary, country facts, space news, natural events, species data, word tools, trivia and World Bank indicators. Provider availability and rate limits can vary.
